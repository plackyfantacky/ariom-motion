Ariom Motion

Interactive scenes, defined in data.

A data-driven animation system connecting 3D scenes, HTML content and user interactions.

Scroll to explore the integration.

Browser integration

Supply a scene. Choose its home.

Load the browser module, provide a mount element and supply your dataset as a JSON URL or JavaScript object. 

const motion = await createMotion({
    mountElement: document.querySelector("#scene"),
    dataset: "./scene.json",
});

The website supplies its markup. The scene dataset defines how that content moves.

Events and control

Give the scene something to respond to.

Named events can connect page controls with animation sequences defined in the dataset.

This text moves when you activate the button. 

motion.emit("demo:play");

Development editor

Author with tools. Ship the runtime.

Development builds can enable the editor through startup options. Production builds exclude its code and styles. 

editor: {
    enabled: true,
}

Scroll back up to reverse the content transitions. The runtime and scene JSON can be updated independently of the consuming website’s build.
